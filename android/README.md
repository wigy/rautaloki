# Rautaloki for Android

The Google Play app is a Trusted Web Activity: a thin Android shell, made with
[Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap), that opens
https://rautaloki.dataplug-oy.com full screen in Chrome. Publisher: **Dataplug Oy**,
package `com.dataplugoy.rautaloki`.

Changes to the web app reach the Android app with the normal deploy; a new app release is
needed only when this project itself changes (name, icon, colours, Android version).

## Files

| Path | What |
|---|---|
| `twa-manifest.json` | the source of the Android project; everything else is generated from it |
| `app/`, `*.gradle`, `gradle*` | generated by `bubblewrap update`, committed as Bubblewrap advises |
| `store/` | Play listing graphics: feature graphic 1024 × 500, phone screenshots 1080 × 1920 |
| `../public/.well-known/assetlinks.json` | Digital Asset Links: lets the app show the site without a browser bar |
| `~/.config/rautaloki-android/upload.jks` | the **upload key**, outside the repo; its password is in `upload-password` there |

**Back up `~/.config/rautaloki-android/`** somewhere safe and private. Google signs the
published app with its own key (Play App Signing), so a lost upload key can be replaced
through Play Console support, but that takes days.

## Build

The toolchain lives in `~/.bubblewrap` (JDK 17, Android SDK with build-tools 36.1.0 and
platform 36), set in `~/.bubblewrap/config.json`.

```bash
cd android
export BUBBLEWRAP_KEYSTORE_PASSWORD=$(cat ~/.config/rautaloki-android/upload-password)
export BUBBLEWRAP_KEY_PASSWORD=$BUBBLEWRAP_KEYSTORE_PASSWORD
npx @bubblewrap/cli@1.27.0 update      # after editing twa-manifest.json; bumps appVersionCode
npx @bubblewrap/cli@1.27.0 build --skipPwaValidation
```

This writes `app-release-bundle.aab` (upload to Play) and `app-release-signed.apk` (install
on a phone with `adb install` to try it). Every upload to Play needs a higher
`appVersionCode`; `update` raises it, `update --skipVersionUpgrade` does not.

## Publishing on Google Play

1. **Create the app** in Play Console (Dataplug Oy's account): name *Rautaloki*, default
   language English (United States), App, Free.
2. **Release:** start with *Testing → Internal testing*, create a release and upload
   `app-release-bundle.aab`. Accept Play App Signing (the default).
3. **Add Google's signing key to the asset links.** Under *Test and release → App integrity
   → App signing*, copy the SHA-256 of the *App signing key certificate* and add it to
   `sha256_cert_fingerprints` in `public/.well-known/assetlinks.json` (keep the upload key's
   entry too), then deploy the web app. Until this is done the app installed from Play shows
   a browser address bar at the top. Check it with
   `https://digitalassetlinks.googleapis.com/v1/statements:list?source.web.site=https://rautaloki.dataplug-oy.com&relation=delegate_permission/common.handle_all_urls`.
4. Install from the internal test link on a phone and check: no address bar, login works,
   the timers speak.
5. Fill in the **App content** tasks with the answers below, then the **Store listing**.
6. Promote the release to *Production* and send it for review.

### App content answers

- **Privacy policy:** https://rautaloki.dataplug-oy.com/privacy.html
- **App access:** all functionality needs an account. Instructions for reviewers: *"Tap 'Sign in with Google' and
  pick any Google account. A new account gets an empty training log; no invitation is
  needed."*
- **Ads:** no ads.
- **Content rating:** category *Reference, News, or Educational* (or *Utility*); no violence,
  sexual content, profanity, drugs, gambling, user-to-user communication or location sharing.
  Expect Everyone / PEGI 3.
- **Target audience:** 18 and over (the privacy policy says it is not for children under 16).
- **Health apps:** *Activity and fitness*. Not a medical device, no health records.
- **Government app, financial features, news app:** no.
- **Data safety:**
  - Collects data: **yes**. Shares data with third parties: **no**.
  - Encrypted in transit: **yes**. Users can ask for deletion: **yes**, in the app (tap the
    name → Delete account) and at https://rautaloki.dataplug-oy.com/privacy.html#delete
  - **Personal info → Email address** (of the Google account used to sign in): collected,
    required, for *Account management*.
  - **Personal info → Name** (from the Google account, shown in the app): collected,
    required, for *Account management* and *App functionality*.
  - **Health and fitness → Fitness info** (lifts, weights, sessions): collected, required,
    for *App functionality*.
  - **App activity → App interactions** (anonymous page view counts in the self-hosted
    Umami): collected, for *Analytics*; not linked to the user.
  - Sign-in is with Google: the app gets the name and verified email only, never a password.
    No location, contacts, photos, audio, files, device IDs or financial data are collected.
- **Account deletion URL** (asked separately): https://rautaloki.dataplug-oy.com/privacy.html#delete
